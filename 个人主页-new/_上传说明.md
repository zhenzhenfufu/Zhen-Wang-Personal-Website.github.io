原来那个 `个人主页照片.jpg` 中文名在 GitHub Pages 上有风险——macOS 存的是分解式 Unicode，
HTML 里写的是组合式，服务器上两者不匹配时图片会 404。换成英文名一劳永逸。

## 在 GitHub 网页上怎么传

1. 打开仓库 `zhenzhenfufu/Zhen-Wang-Personal-Website.github.io`
2. **Add file → Upload files**，把上面 9 个文件 + `portrait.jpg` 一起拖进去
3. 底下写一句 commit message，点 **Commit changes**
4. 等 1–2 分钟，Pages 自动重新发布

旧的 `index.html` 会被覆盖，这是对的。旧照片文件可以留着不管。
